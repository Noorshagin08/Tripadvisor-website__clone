# Tripadvisor-website__clone


A Tripadvisor website clone created using HTML and CSS as a practice project.

## Features

- Responsive navigation bar
- Travel destination cards
- Things to do section
- Interest and recommendation sections
- Footer section
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design

## Purpose

This project was created to practice HTML and CSS concepts such as Flexbox, layouts, responsive design, spacing, and image styling.
